# LinkedIn Post Generator Profile

Copy this file to `PROFILE.md` before using the skill for a recurring personal or company voice. Replace the values inside `{{...}}`. Keep the completed `PROFILE.md` private.

If a field does not apply, use `N/A` rather than inventing information.

```yaml
AUTHOR_NAME: "{{AUTHOR_NAME}}"
ACCOUNT_TYPE: "{{ACCOUNT_TYPE}}" # personal or company
COMPANY_NAME: "{{COMPANY_NAME}}"
COMPANY_POSITIONING: "{{COMPANY_POSITIONING}}"
AUTHOR_BACKGROUND: "{{AUTHOR_BACKGROUND}}"
TARGET_AUDIENCE: "{{TARGET_AUDIENCE}}"
PRODUCT_OR_SERVICE: "{{PRODUCT_OR_SERVICE}}"
VOICE_TRAITS: "{{VOICE_TRAITS}}"
TONE_PREFERENCES: "{{TONE_PREFERENCES}}"
CTA_PREFERENCE: "{{CTA_PREFERENCE}}"
LINKEDIN_URL: "{{LINKEDIN_URL}}"
TOPICS_TO_AVOID: "{{TOPICS_TO_AVOID}}"
CLAIMS_REQUIRING_EVIDENCE: "{{CLAIMS_REQUIRING_EVIDENCE}}"
```

## How to fill it in

- `AUTHOR_NAME`: the person whose voice the content represents.
- `ACCOUNT_TYPE`: whether the post is for a personal profile or a company page.
- `COMPANY_NAME`: the organization or brand, if applicable.
- `COMPANY_POSITIONING`: the company’s practical point of view and what it wants to be known for.
- `AUTHOR_BACKGROUND`: relevant experience that can be used when it is directly supported.
- `TARGET_AUDIENCE`: the people the post should reach.
- `PRODUCT_OR_SERVICE`: the relevant product, service, or area of work.
- `VOICE_TRAITS`: a short description such as direct, conversational, technical, calm, or skeptical.
- `TONE_PREFERENCES`: any tone constraints, including how sharp, personal, or educational the writing should be.
- `CTA_PREFERENCE`: whether to use a question, takeaway, soft invitation, link, or no CTA.
- `LINKEDIN_URL`: a profile or company-page URL when relevant.
- `TOPICS_TO_AVOID`: subjects, claims, or wording that should not be used.
- `CLAIMS_REQUIRING_EVIDENCE`: claims that always need a source, metric, or explicit user-provided context.

Do not add passwords, API keys, private client information, confidential strategy, or other secrets to this file.
